## Confirmed deliberate differences

1. Prototype role switching and “View as” controls are not production features and will not be copied; authenticated identity, reporting-line visibility, permissions, and RLS remain authoritative.
2. Prototype sample names, tasks, Goals, timestamps, files, and counts will not replace live data.
3. Production-only record filters, immutable audit context, validation errors, conflict states, and permission-safe controls remain available inside the approved visual hierarchy.
4. The explicit urgent-capture shortcut is implemented entirely in the presentation layer: it records the user’s explicit urgent safety/compliance intent as visible capture context, then relies on the existing wording-triggered question and server-authorised confirmation flow. No action contract or classification rule changed.
5. The Weekly email summary utility opens the real delivery schedule/history instead of reproducing the prototype’s simulated preview and test-send buttons. The current frontend has no read-only preview action, and this UI-only pass does not invent or bypass one.
